# Restaurant – Aplicație mobilă

## 1. Scopul proiectului
Scopul proiectului este realizarea unui prototip interactiv al unei aplicații mobile de restaurant, care permite utilizatorilor să vizualizeze meniul, să selecteze produse și să simuleze adăugarea acestora în coșul de cumpărături.

## 2. Funcționalități principale
- Vizualizarea meniului restaurantului.
- Navigarea între categoriile Burger și Pizza.
- Selectarea produselor din meniu.
- Vizualizarea detaliilor produselor.
- Simularea adăugării produselor în coș.
- Vizualizarea coșului de cumpărături.
- Navigarea între ecranele aplicației.

## 3. Autorul proiectului
Proiect realizat individual.
Responsabilități: planificarea proiectului, analiza cerințelor, proiectarea interfeței, realizarea prototipului interactiv, testarea și documentarea.

## 4. Instrumente utilizate

- **Figma** – proiectarea interfeței și realizarea prototipului interactiv.
- **Trello** – organizarea activităților proiectului.
- **ClickUp** – elaborarea planului Gantt.
- **Microsoft Word / Google Docs** – documentarea cerințelor aplicației.
- **GitHub** – păstrarea și gestionarea fișierelor proiectului.
